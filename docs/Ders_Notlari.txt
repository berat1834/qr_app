==================================================================
                     3. QR SCANNER (KAMERA)
==================================================================

ÖZELLİKLER:
• Gerçek zamanlı kamera görüntüsü
• QR kod otomatik algılama
• Flaş açma/kapama
• Sonuç gösterme ve kaydetme
• İzin yönetimi

TEMEL KAVRAMLAR:
- StatefulWidget -> Değişebilen durum
- async/await -> Asenkron programlama
- setState() -> UI güncelleme
- MobileScanner -> QR okuma widget'ı
- Permission.camera -> Kamera izni

KOD ÖRNEĞİ:
```
MobileScanner(
  onDetect: (capture) {
    setState(() {
      result = barcode.rawValue;
    });
  },
)
```

==================================================================
                    4. QR GENERATOR (OLUŞTURMA)
==================================================================

ÖZELLİKLER:
• 4 farklı QR türü: Metin, URL, WiFi, Telefon
• Dropdown menü ile tür seçimi
• Dinamik giriş formları
• QR kod önizleme
• Panoya kopyalama

TEMEL KAVRAMLAR:
- TextEditingController -> Metin girişi kontrolü
- switch-case -> Çoklu koşul kontrolü
- DropdownButton -> Açılır menü
- QrImageView -> QR kod görseli
- Clipboard -> Sistem panosu

WiFi QR FORMAT:
WIFI:T:WPA;S:WiFiAdi;P:Sifre;;

==================================================================
                    5. HISTORY SCREEN (GEÇMİŞ)
==================================================================

ÖZELLİKLER:
• Tüm QR aktivitelerini listeleme
• Tarama/oluşturma durumu gösterme
• Zaman damgası (1 saat önce, 2 gün önce)
• Silme konfirmasyonu
• PopupMenu (sağ tık menüsü)

TEMEL KAVRAMLAR:
- ListView.builder -> Performanslı liste
- DateTime -> Zaman işlemleri
- RegExp -> Düzenli ifadeler
- showDialog -> Modal dialog
- PopupMenuButton -> Sağ tık menüsü

ZAMAN HESAPLAMA:
```
final difference = DateTime.now().difference(pastTime);
if (difference.inDays > 0) return '${difference.inDays} gün önce';
```
